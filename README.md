# GoFaderline : versions publiées

Ce dépôt contient uniquement les **installeurs** de GoFaderline, l'application Windows qui pilote une **TC-Helicon GoXLR Mini** à la place de l'app officielle. Le code source n'est pas publié ici.

## Installer

1. Ouvrez la page [Releases](https://github.com/Zaigda/GoFaderline-releases/releases/latest).
2. Téléchargez `GoFaderline_<version>_x64-setup.exe` et lancez-le (installation pour votre compte Windows, sans droits administrateur).
3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**, puis **Exécuter quand même** : l'installeur n'est pas signé par un certificat payant.

Les mises à jour suivantes se font directement dans l'application (Réglages → Général → Mettre à jour) ; elles sont vérifiées par une signature propre à GoFaderline avant d'être installées.

## Crédits

GoFaderline embarque le moteur open source [GoXLR Utility](https://github.com/GoXLR-on-Linux/goxlr-utility) (licence MIT), dont la licence est incluse dans l'installation.
